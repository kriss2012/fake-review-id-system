FRAUD CLASSIFICATION ENGINE // MATHEMATICAL FOUNDATIONS

HOW THE FAKE REVIEW IDENTIFIER WORKS (IN DETAIL)

The VeriView AI fraud engine leverages Optical Character Recognition (Pytesseract), Martin Porter's morphological suffix stripping stemmer, sublinear TF-IDF vector space mapping, and a regularized Logistic Regression sigmoid classifier. Explore the exact transformation pipeline and mathematical equations below.

END-TO-END FRAUD INSPECTION PIPELINE:
01

MULTIMODAL INGESTION & OCR

Direct text, plaintext files, or screenshot images are ingested. Pytesseract extracts pixel text via Otsu binarization and LSTM OCR algorithms.

02

REGEX & PORTER STEMMING

Punctuation and numbers are stripped. Words are lowercased, filtered against NLTK English stopwords, and reduced to grammatical roots via Porter Stemming (e.g. "arrived" → "arriv").

03

TF-IDF VECTOR SPACE (84-D)

Preprocessed stems are mapped into a high-dimensional vector space using Term Frequency-Inverse Document Frequency weighting with sublinear scaling.

04

LOGISTIC SIGMOID BOUNDARY

A single linear decision boundary \(\mathbf{z} = \mathbf{w}^T\mathbf{x} + b\) separates fake from original reviews. Weights are regularized with L2 ridge penalty.

05

DECEPTION SCORING & ATTRIBUTION

Sigmoid resolves \(P(\text{Fake} \mid \mathbf{x}) \in [0, 1]\). Local linear feature contributions \(w_j \cdot x_j\) quantify which exact words triggered fraud flags.

MATHEMATICAL FORMULATIONS:
1. LOGISTIC SIGMOID:
P(Fake | x) = 1 / [1 + exp(-(w^T · x + b))]
2. BINARY LOG-LOSS:
L(w) = - ∑ [ y_i · ln(p_i) + (1 - y_i) · ln(1 - p_i) ] + (1 / 2C) · ||w||_2^2
3. TF-IDF WEIGHT:
TF-IDF(t, d) = [1 + log(TF(t, d))] × [log((1 + N) / (1 + DF(t))) + 1]
4. FEATURE ATTRIBUTION:
Attribution(stem_j) = w_j × x_j   [+ values → Fake, - values → Original]
